grill 결정(2026-11-26): 기업 정보 탭(맨 앞), 공간당 1개, 기업명 기본값=작업 공간 이름(저장해야 표시), 소개는 일반 텍스트 1,000자, 링크 고정 4칸(https), 저장된 공간의 공개 공고에 자동 표시, 「매장」→「장소」 화면 문구 전체, JobPosting 은 2단계.

## settings-company.excalidraw

1. 「기업 정보」 탭을 맨 앞에: 공고 전체에 쓰이는 기본 정보라 먼저 채우게.
2. 「매장 관리」→「장소 관리」: 매장이 아닌 근무지(사무실·현장)도 담게.
3. 기업명 기본값=작업 공간 이름 + 안내: 빈 칸 부담을 줄이고, 저장 전 노출 없음을 알림.
4. 기업 소개 Textarea 1,000자: 서식 없이 줄바꿈만.
5. 링크 4칸(홈페이지·블로그·인스타그램·유튜브): https 만 허용, 빈 칸은 공고에서 숨김.
6. 저장 상태 배지: 공고에 지금 보이는지 바로 확인.
7. 「공고에서 보기」: 저장 결과를 공개 화면으로 확인(모집 중 공고가 없으면 숨김).

## public-posting.excalidraw (모바일) — A안 확정(11-26), 헤더 단순화 지시 반영

1. 기업명: 머리글 1줄(text-base font-semibold). 헤더 Card(테두리·그림자) 제거 — 본문 블록이 첫 시각 요소.
2. 상태·마감·장소: 작은 회색 1줄(상태 점 + 마감일(D-n) + 「장소명 외 n곳」). 주소 전체는 헤더에서 뺌. 기업 정보 없는 공간은 기업명 없이 같은 머리글 + 주소 줄(지금 정보 유지).
3. 기업 소개: Card 아님 — 공고 푸터처럼 위 구분선 + 작은 회색 글씨(에디 11-26: 비중 낮게). 설정 「공고에 기업 소개 표시」 스위치로 끌 수 있음. 지원 영역 아래, 줄바꿈 유지.
4. 근무 장소: 소개 카드 안에 장소별 도로명 주소(MapPin) — 헤더에서 옮긴 정보, 2단계 JobPosting 화면 일치용.
5. 링크: lucide Globe·BookOpen·Instagram·Youtube + 글자 라벨, Button outline sm, 새 탭 rel=noopener.
