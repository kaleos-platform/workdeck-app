# Sentry「확인 필요」분석 요청 → GitHub 이슈 와이어프레임

화면: admin/errors(`src/components/admin/errors-table.tsx`) 목록·상세 Sheet + Slack 요약(`src/lib/sentry/autofix-digest.ts`). 미리보기: `wireframe.html` / `wireframe.png`

1. 확인 필요 행 동작: [분석 요청] [제외]. 수정 요청은 상세 패널로.
2. 진행 상태 배지: 분석 요청됨 → 분석 중 → 완료 또는 분석 실패 [다시 요청].
3. 완료 배지 = 판정(고칠 것/지켜볼 것/무시) + GitHub 이슈 링크. 판정은 러너가 고정 코드로 메모에 남김.
4. 판정별 다음 버튼: 고칠 것 → [수정 요청], 지켜볼 것 → 그대로, 무시 → [제외 확정].
5. 상세 Sheet「분석」섹션: 판정·확신도·자동 수정 가능 여부·이슈 링크. 분석 본문은 이슈에만.
6. Slack 요약: 확인 필요 줄마다 [분석 요청](운영자만, PR 올리기와 같은 검사), 새로 끝난 분석은「분석 완료」줄.
