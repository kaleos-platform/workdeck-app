# 오프닝 이전 큐(어드민) 와이어프레임

화면: `admin.workdeck.work/admin/opening-migrations` (운영자 전용, 신규 route)

1. 사이드바에 「오프닝 이전」 추가 — 도입 신청과 같은 운영 대기열 성격이라 그 아래에 둔다.
2. 상태 탭(승인 대기·차단·진행 중·완료·보류) — 운영자가 할 일은 '승인 대기'뿐이라 기본 탭으로 연다.
3. 표 한 줄 = 브랜드 1개 job. 가입자 이메일·브랜드명을 나란히 둬 오매칭(남의 이메일로 만든 오프닝 계정)을 눈으로 대조한다.
4. 상세는 오른쪽 Sheet — 목록을 유지한 채 여러 건을 차례로 검토하기 위해 별도 페이지 대신.
5. 연락처 감지 조각은 상세에서만 보여 준다(목록엔 건수만). 완료·보류 시 삭제된다는 안내를 함께 둔다.
6. 승인은 AlertDialog로 브랜드명·가입자 이메일을 한 번 더 확인 — 승인하면 적용·보장가·메일까지 자동 진행되므로.
7. 보류는 확인 없이 바로(되돌릴 필요가 없는 안전한 동작). 차단 행에는 승인 버튼을 두지 않는다.
