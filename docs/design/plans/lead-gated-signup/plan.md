# 도입 문의 기반 가입 — 화면 계획

계획 원문: `docs/superpowers/plans/2026-11-25-lead-gated-signup.md`

## signup.excalidraw

1. 링크 없이 `/signup` → 가입 폼 대신 안내: 도입 문의가 가입 입구임을 알린다.
2. 「도입 문의하기」가 주 버튼: 모든 가입자가 문의를 거치게 한다.
3. Google 버튼은 남긴다: 문의한 이메일의 Google 계정이면 서버가 이메일 일치로 통과시킨다(명단 노출 없음).
4. 가입 링크로 오면 이메일을 리드 이메일로 고정: 다른 이메일로 가입해 막히는 일을 없앤다.
5. Google 차단 안내: 어떤 계정이 왜 막혔는지와 다음 행동 두 가지.
6. 문의 완료 화면에 「바로 가입하기」: 문의 직후 가입(기록 목적 확정).

## admin-leads.excalidraw

1. 「유입 경로」 열: 리드 utm·referrer 를 한눈에.
2. 「가입」 열 + 「신청 N회」: 전환 여부·중복 신청을 목록에서 바로.
3. 행별 「안내 메일」 버튼: 종료 행은 비활성, 마지막 발송 시각 표시.
4. 발송 다이얼로그: 운영자 메시지 300자(선택).
5. 메일 미리보기: 보내기 전에 실제 본문 확인.
