# 생산 차수 수정 창 — 입고 완료와 재고 입고 분리

화면: `production-run-form-dialog` 진행 단계. 미리보기: `wireframe.html` / `wireframe.png`. 계획: `docs/decks/seller-hub/2026-11-20-production-stockin-decouple-plan.md`

1. 상태 Select 에서 「입고완료」를 고를 수 있다(기존 「목록 상태 메뉴에서 처리」 안내 삭제).
2. 입고완료를 고르면 그 아래에 입고 완료 창과 같은 보관 위치 분배 입력이 펼쳐지고 [수정]으로 함께 저장한다.
3. 자체 위치(사무실) 분배가 있으면 「사무실 재고에 입고 등록」 체크(기본 해제). 체크 시에만 재고 위치 [입고] 건 생성.
4. 입고 완료 차수는 분배 결과를 읽기 전용 표로 보여 준다(연동 위치는 대조 대기/완료).
5. 「사무실 입고 등록」: 미등록 자체 위치 행 수량 수정·입고일·[입고 등록]. 등록된 행은 「등록됨」(행마다 1회).
6. 「발주 완료로 되돌리기」는 등록된 사무실 입고가 없을 때만 보인다.
