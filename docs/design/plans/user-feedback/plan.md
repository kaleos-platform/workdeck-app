# 이용자 의견 남기기 — 화면 계획

설계: `docs/superpowers/specs/2026-11-27-user-feedback-design.md`, 계획: `docs/superpowers/plans/2026-11-27-user-feedback.md` Task 0

## dialog.excalidraw

1. 사이드바 「의견 남기기」: 로그아웃 위에 두어 어느 화면에서든 한 번에 닿게 하고, 접힘 상태는 아이콘+Tooltip으로 자리를 아낀다.
2. 유형 RadioGroup 5개: 분류를 이용자가 고르게 해 어드민이 사후 분류하는 수고를 없앤다.
3. 본문 Textarea + 안내 문구: 무엇을 적을지 알려 주어 재문의 없이 바로 조치할 수 있는 내용을 받는다.
4. 이미지 최대 3장(제거 X·추가 버튼·GIF 안내): 오류 재현에 화면이 가장 빠르고, 장수 제한으로 저장 비용을 막는다.
5. 상한 도달 안내: 의견은 접수되고 이미지만 빠졌음을 알려 이용자가 제출이 실패했다고 오해하지 않게 한다.

## admin-list.excalidraw

6. 상단 내비 「의견」: 도입 신청 옆에 두어 운영자가 기존 확인 동선 그대로 찾게 한다.
7. 요약 줄: 상태별 밀린 건수와 첨부 용량(500MB 상한 대비)을 한눈에 보게 한다.
8. 필터 Select 유형·상태: 접수 건만 또는 오류만 빠르게 추려 처리 순서를 정한다.
9. Table(이미지 없음): 본문 요약·첨부 수만 보여 목록을 가볍게 하고, 이미지는 상세에서만 연다. 모바일은 행 카드.

## admin-detail.excalidraw

10. 본문 전체·화면 경로·브라우저·제출자 mailto·작업 공간: 재현에 필요한 맥락과 답장 경로를 한 화면에 모은다.
11. 상태 Select + 내부 메모 + 저장: 처리 진행을 기록하고, 메모는 제출자에게 보이지 않게 둔다.
12. 첨부 썸네일·삭제 예정일·「첨부 지금 삭제」(destructive, AlertDialog 확인): 자동 정리 시점을 투명하게 보이고, 개인정보가 담긴 이미지를 즉시 지울 수 있게 한다.

## 흐름 (flow.excalidraw)

사이드바 버튼 → Dialog 제출 → Slack 알림 → 어드민 목록 → 상세(상태·첨부 삭제) → 완료 30일 뒤 cron 자동 정리.
