# 사용자 새 작업 공간 만들기 와이어프레임

화면: 사이드바 작업 공간 카드(`SpaceSwitcher`) + 새 Dialog + 기존 구독 모달(`SubscribeDialog`). 미리보기: `wireframe.html` / `wireframe.png`

1. 사이드바 작업 공간 카드는 공간이 1개여도 열린다. 메뉴 맨 아래 「＋ 새 작업 공간 만들기」. 홈 맥락 줄(SpaceContext)은 바꾸지 않는다.
2. 이름 입력 Dialog 하나(60자, 같은 이름 소유 공간이 있으면 입력란 아래 오류). 만들면 새 공간으로 전환해 내 워크덱 홈으로 이동. 업무는 기존 화면에서 추가.
3. 소유 공간이 5개면 메뉴 항목 비활성 + 「소유한 작업 공간은 5개까지입니다. 더 필요하면 문의해 주세요.」
4. 체험은 소유자 기준 업무별 1회. 이미 체험한 업무는 새 공간에서 바로 구독 모달(「다른 작업 공간에서 이 업무 체험을 이미 사용했습니다」 한 줄 추가).
5. 오프닝 이전 대기 job 은 어드민 생성과 같이 MULTIPLE_OWNER_SPACES 로 BLOCKED(사용자 화면 노출 없음).
6. 어드민 「새 Space 만들기」는 지금처럼 체험 허용.
