같은 이름이 있으면 입력란 아래 「이미 같은 이름의 작업 공간이 있습니다」.

4새 공간에서 이미 체험한 업무 열기 → 구독 모달

모집 관리 구독

다른 작업 공간에서 이 업무 체험을 이미 사용했습니다. 이 공간에서는 구독 후 바로 쓸 수 있습니다.
월 ○○원(VAT 포함) · 결제일: 오늘
취소구독 시작

체험을 안 쓴 업무는 지금처럼 「추가」 → 체험 7일 시작. 구성원(소유자 아님)은 기존 토스트 「소유자에게 요청하세요」.

결정 항목
  1. 사이드바 작업 공간 카드는 공간이 1개여도 열린다(맨 아래 「＋ 새 작업 공간 만들기」). 홈 맥락 줄(SpaceContext)은 바꾸지 않는다.
  2. 이름 입력 팝업(Dialog) 하나. 만들면 새 공간으로 전환해 내 워크덱 홈으로 이동. 업무는 만든 뒤 기존 화면에서 추가.
  3. 소유 공간 5개면 메뉴 항목 비활성 + 문의 안내.
  4. 체험은 소유자(사용자) 기준 업무별 1회. 이미 체험한 업무는 새 공간에서 바로 구독 모달(안내 한 줄 추가).
  5. 오프닝 이전 대기 job 은 어드민 생성과 같이 MULTIPLE_OWNER_SPACES 로 BLOCKED(화면 노출 없음, 운영 큐에서 처리).
  6. 어드민 「새 Space 만들기」는 지금처럼 체험 허용.
