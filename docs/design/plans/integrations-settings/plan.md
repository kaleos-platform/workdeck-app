값은 모두 예시입니다.

① 탭 3개, 탭에 확인 필요 건수 표시
처음 열면 건수가 있는 첫 탭을 엽니다.
② 탭을 열면 맨 위에 확인 필요 목록
버튼을 누르면 해당 카드 위치로 이동합니다.
③ 문제 있는 카드를 탭 안에서 위로
카드 기능은 그대로 둡니다.
④ 문제가 없으면 건수와 목록을 숨김

확인 필요 기준 (구현)
외부 서비스: 쿠팡 연결 테스트 실패 (자격증명 저장 이후 최신 결과)
에이전트: 토큰 만료 또는 7일 이내 만료 (켜진 에이전트, 가장 늦은 토큰 기준)
비밀값: 비밀값 만료 또는 7일 이내 만료
제외: Slack 미연결, 에이전트 꺼짐, 쿠팡 미등록

기술 메모
건수는 탭을 열기 전에 필요합니다. 지금은 카드마다 따로 불러오므로 페이지 서버에서 요약을 계산합니다.
Slack 연결 후 돌아오면 외부 서비스 탭을 엽니다.
MEMBER는 탭 없이 MCP 가이드만 봅니다.
MCP 가이드는 에이전트 탭에 둡니다. 개발자 탭은 비밀값 탭으로 바꿨습니다(그림 option-b-developer보다 이 메모가 최신).
