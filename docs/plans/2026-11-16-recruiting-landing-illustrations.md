# 모집 관리 랜딩 기능 이미지 일러스트화 (2026-11-16)

## 목표

`workdeck.work/recruiting` 기능 행 5개의 실제 스크린샷(#1473)을, 실제 화면을 바탕으로 재구성한 일러스트 이미지로 바꾼다. 모바일에서도 글자가 읽히고 기능의 핵심만 보이게 한다. (사용자 grill 결정 2026-11-16)

## 결정 사항

1. 공고 디자인 행: 「워크덱 제공」 공고 템플릿 여러 개를 고르는 갤러리 + 공고를 직접 고치는 에디터를 한 이미지에. (템플릿 브랜드 정리·차단 해제 완료 #1484→#1485 — 표시=실제 충족)
2. 링크·지원서 행: 공고 상세 페이지와 지원서 페이지를 한 화면에 나란히, HTML 코드 조각과 채용 사이트 로고(알바몬·사람인·알바천국·잡코리아)를 상징적으로.
3. AI 행: Claude·ChatGPT·Gemini 로고 + 대화 형식(채용 진행 현황 조회, 공고 초안 제작) 예시. **로고는 실제 연결 시험에 성공한 서비스만** 넣는다(ego 브라우저로 직접 시험). 대화 UI는 특정 앱을 흉내 내지 않은 중립 채팅 UI.
4. 로고: 공식 공개 로고 사용(사용자 결정). 제휴처럼 보이지 않게 각 상표 소유 문구를 페이지에 둔다.
5. 지원자 관리·이메일 행도 같은 일러스트 톤으로 재제작(5개 통일).
6. 제작: HTML/CSS로 화면을 단순화·확대 재구성 → gstack browse로 2배 렌더 → webp. 새 의존성·외부 생성 도구 없음. 데모 데이터는 가상 회사 「한빛인력」.
7. 순서: 공고 디자인 행 시안 1장 → 사용자 승인 → 나머지 4장.

## 리스크

- 공식 로고 사용 규정(각사) — 사용자 판단으로 사용, 상표 고지 문구로 제휴 오해 방지.
- ChatGPT 커넥터는 유료 플랜·개발자 모드가 필요할 수 있음 → 불가 시 해당 로고 제외.

## Codex 리뷰 (adversarial) — 지적 6건

1. [high] 채용 사이트 로고 = 게시 호환 미검증 → 보류: 사용자가 각 사이트 HTML 붙여넣기를 직접 검증했다고 확인(2026-11-17), 4개 로고 모두 표기.
2. [high] OAuth 시험 정리 범위 → 반영: 시험 사용자는 qa2(「한빛인력」 공간)만 사용. 정리 = 외부 커넥터 삭제 + 워크덱 OAuth 동의/연결(에이전트 바인딩·토큰) 철회 + qa2 세션 로그아웃. 정리 후 기존 자격 증명으로 MCP 호출 401 확인. 실패·중단 시에도 같은 절차, 결과를 보고에 기록.
3. [high] 목록 조회만으로 초안 제작 표시 → 반영: 서비스별로 `hiring_get_application_stats`(현황)와 `hiring_propose_posting_draft`(초안 제안→승인 대기) 각각 시험. 초안은 거부 처리. 그림·문구에 「승인 후 작성 중 공고로 생성」 명시.
4. [medium] 상표 사용 조건 → 사용자 결정(공개 로고 사용)으로 진행, 출처 URL·사용 조건 확인 메모를 `public/marketing/logos/SOURCES.md`에 기록, 상표 소유 고지 문구 노출. 로고 가이드가 금지하는 변형(색·비율 변경)은 하지 않음.
5. [medium] 요금 페이지 영향 → 반영: `screenshots[0]`도 새 지원자 관리 일러스트로 교체(파일명 유지), `/pricing/recruiting` 함께 검증.
6. [medium] Ego 지원 범위 → 사용자 지시(「ego 브라우저로 직접」)로 ego-browser 직접 조작, 로그인·2단계 인증은 사용자가 수행. 검증 불가 서비스는 표시하지 않는 완료 조건 유지.

## AI 연결 시험 결과 (2026-11-17)

- ChatGPT: 플러그인 → 「사용자 지정 MCP 서버 추가」(OAuth) → qa2(한빛인력) 승인 → 채팅에서 지원 현황 요약 조회 성공, 공고 초안 제안 → 워크덱 승인 대기 등록 성공(거부 처리). 정리: 시험 대화 삭제, 플러그인·연결 삭제, ego qa2 로그아웃. 남은 것: 워크덱에 OAuth 연결 해제 화면이 없어 서버측 OAuth 토큰 즉시 폐기는 미확인(qa2 테스트 계정).
- Gemini: CLI는 API 선불 크레딧 소진(402)으로 시험 불가, 웹은 미로그인. **사용자 결정으로 시험 없이 로고 표기**.
- Claude: 기존 MCP 연동(M1~M5) 운영 검증 + 11/15 hiring 도구 토큰 호출 확인.

## 구현 결과 (2026-11-17)

- 사용자 「계속 진행」으로 시안 1 승인 → 나머지 4장 같은 톤(800×500, 2배 렌더 1600×1000, webp 58~82KB).
- 링크·지원서: 공개 공고/지원서 실화면(qa2 평택 공고) 기준, HTML 조각은 `render-embed-html` 출력 구조, 로고 4개 원본 그대로.
- 지원자: 실제 탭·「N개 선택됨」 일괄 상태 변경 바·「메모 남기기」. 이메일: `mail.ts` 실제 제목·본문·공고별 메일 설정 라벨. AI: 중립 채팅 UI + 승인 대기 카드(실제 문구), 「승인 후 작성 중 공고」 명시.
- 상표 고지: 링크 행·AI 행 이미지 캡션, 테스트로 고정.
