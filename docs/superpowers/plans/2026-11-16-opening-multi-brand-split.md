## 목표

## 현재 막히는 점 (실측, 읽기 전용 prepare)

- 두 브랜드가 공고를 서로 복사해 써서, 한 브랜드 공고 안에 **다른 브랜드 소유 이미지·디자인**이 들어 있다. prepare는 소유 브랜드가 다르면 막는다.
  - `opening-prepare.ts:495` 파일 소유 → `ASSET_SCOPE_MISMATCH` (510 공고 52·템플릿 12, 511 공고 83·템플릿 15)
  - `opening-prepare.ts:678` content(디자인) 소유 → `RESOURCE_SCOPE_MISMATCH`
- 나머지는 브랜드 단위로 이미 동작한다. 원장 sourceRef는 원본 id 기준(전역 unique), Storage 경로는 `{spaceId}/migration/...`라 Space가 다르면 각자 복사된다.

## 변경 (최소, 기본 off)

1. `prepareOpeningCustomer` 옵션 `siblingBrandIds?: string[]`, CLI `prepare --sibling-brands <id,...>`.
   - **가드**: 원본 DB에서 대상 브랜드와 각 형제 브랜드가 활성 관리자(brand_member.member_type='admin', status=1, member.status=1)를 1명 이상 공유해야 한다. 아니면 원본 읽기 전에 `SIBLING_BRAND_UNVERIFIED`로 중단. 허용 쌍은 CLI의 정확한 id 목록뿐.

   - 요약에 형제 소유로 허용한 파일·디자인 수(`siblingOwned`)를 따로 집계해 사람 검토 때 보인다.
2. `OPENING_URL_REMAINS` 경고 오탐 수정: Excalidraw scene 최상위 `source`(화면에 안 보이는 메타데이터, AAK 실측 312건 전부)를 검사에서 제외. 적재 결과는 바뀌지 않는다.

### 2026-11-17 운영 승인과 도구 보완

사용자가 「이전을 진행하세요」라고 세 고객의 운영 이전을 승인했다. 추가 확인을 반복 요청하지 않고 승인된 범위의 준비·dry-run·적재·사후 검증을 진행한다. 지원자·계정·원본 삭제·고객 메일 발송은 이번 데이터 적재에 포함하지 않는다.

- 단일 프레임 AVIF는 디코더에서 AV1 여부를 확인하고 원래 해상도·방향·투명도를 유지한 메타데이터 없는 PNG로 변환한다. 다른 미지원 파일과 다중 프레임 AVIF는 계속 차단한다.
- `review.json`의 선택 필드 `assetScopes`는 원본 고객 범위에 묶인다. 알려진 소유자 예외는 정확한 파일 키 SHA256(`ref`)·원본 소유 브랜드가 함께 일치해야 한다. 다른 파일·다른 소유자에 승인이 확장되지 않는다.
- 디에스인의 브랜드 1 자산은 현재 공고·템플릿의 참조와 공통 샘플·생성 content 관계를 대조하고 정확한 키별로 검토 기록을 남겼다. 브랜드 1 전체를 전역 허용하지 않는다.
- 소유 정보가 없는 디에스인 파일 4개는 같은 「간편 지원하기」 공통 버튼 2종의 이미지·scene이다. 원본 생성 코드의 `default_content_link` 공유 방식과 400개 content 참조, 실물 이미지 및 scene의 단순 버튼 문구를 확인했다. 원본 파일 키 해시와 **원본 바이트 SHA256**까지 함께 기록한 명시적 공통 자산 검토만 허용하며, 파일이 바뀌면 `ASSET_REVIEW_STALE`로 중단한다. 그 밖의 소유 불명 자산은 계속 차단한다.

### 2026-11-17 보장가 및 고객 완료 안내 후속

사용자가 남은 작업을 계속 진행하라고 승인했고, 실제 화면 검수는 「고객에게 맡기고 완료 안내를 보내세요」라고 명시했다.

- 세 Space에 기존 `migrate-grant` 운영 도구로 모집 관리 보장 공급가 12,273원(부가세 포함 월 13,500원)을 등록했다. CLI 실행에도 운영 CA 검증을 강제했다. 모집 아이템은 `ENDED`, 구독은 `TRIALING`이며 실제 청구는 세 Space 모두 0건이다. 유료 구독을 자동 활성화하지 않았다.
- 기존 체험 종료일(KST)은 그대로다: 디에스인 11/20 14:56, IVECOBUSAN 11/23 09:21, 올댓모델 11/23 16:55. 현재 운영 결제는 일시 중지 상태가 아님을 확인했다. 이전 안내에 과거의 「결제 준비 중·종료 후에도 무료」 문구를 재사용하지 않았다.
- 기존 브라우저 세션은 「의식주의」 공간만 접근 가능하고 고객 세 Space·운영 어드민 접근 권한이 없었다. 고객 로그인 세션이나 멤버십을 임의 생성하지 않고 사용자에게 브라우저를 넘겼다. 사용자 결정에 따라 실제 편집·미리보기·HTML 복사 화면 검수는 고객 확인으로 남긴다.
- 지정된 세 Space의 실제 OWNER 이메일로 고객별 완료 안내를 발송했고 Resend에서 세 요청의 접수 ID를 받았다. 메일은 각 고객의 이전 건수, 「작성 중」 공고 확인·편집·미리보기·HTML 복사 방법, 보장가, 체험 종료일과 구독 선택 방법을 포함한다. 중복 발송 방지 키와 로컬 발송 영수증을 사용했다.
- Resend 키는 발송 전용이므로 전달 상태 조회는 `401 restricted_api_key`로 제한된다. 세 건의 발송 접수 ID는 확인했지만 수신함 도착·열람까지 확인했다고 주장하지 않는다.
