# 업무별 체험·면제와 구독 현황 분리

## 확정 요구사항

- Space × 업무마다 최초 활성화 시 7일 체험. 비활성화·재추가와 관계없이 이력을 보존한다.
- 운영자는 구독 현황에서 업무별 체험 종료일을 미래로 연장한다. 날짜는 한국 시간 해당 날짜 말일까지로 해석한다. +7일·+30일은 현재 종료일과 오늘 중 늦은 날을 기준으로 한다.
- 체험 만료는 자동 결제 예약이 아니다. 사용자가 명시적으로 유료 구독을 시작해야 청구한다. 기존 유료 구독의 결제일은 변경하지 않는다.
- 업무별 면제는 접근 허용과 모든 청구 경로의 제외를 함께 적용한다. 면제 해제만으로 과거 미청구 기간을 소급 청구하지 않는다.
- 기존 Space 전체 면제는 유지한다. 전체 면제 중에는 업무별 면제가 해제되어도 전체 면제가 우선한다.

## 데이터와 전환

`SpaceDeckAccess`에 `spaceId`, `deckAppId`, `trialEndsAt`, `exemptFlag`, `exemptNote`를 둔다. Space와 BillingDeckProduct에 FK, Space × 업무 유일 제약을 둔다. 체험·면제는 결제 라인아이템과 분리한다. RLS를 활성화하고 anon/authenticated 권한을 회수한다.

기존 `SpaceSubscription.trialEndsAt`는 활성·비활성 DeckInstance가 있는 과금 업무에만 원래 종료일 그대로 백필한다. 기존 Space 전체 면제는 복사·해제하지 않고 호환 정책으로 유지한다. 신규 업무에는 공간의 과거 체험을 물려주지 않는다. 기존 API의 공간 단위 체험 날짜는 호환용으로 남기되 권한 판정에는 사용하지 않는다.

업무 추가와 체험 이력 생성은 같은 transaction에 넣어 활성화 실패 시 체험을 소비하지 않는다. 최초 생성은 `createMany(skipDuplicates)`의 `ON CONFLICT DO NOTHING`으로 처리하고, null 종료일만 조건부 갱신해 동시 요청에도 이력을 덮어쓰지 않는다. 무료 업무·면제 업무·이미 구독한 업무에는 새 체험을 시작하지 않는다.

## 접근과 청구

기존 판정 순서를 유지하면서 업무별 정책을 사용한다: 무료 업무 → Space 전체 또는 해당 업무 면제 → 유효한 유료 구독 → 해당 업무 체험 → 기존 유예 → 결제 중지 → 잠금.

신규·일할 추가 청구에서는 면제된 업무의 결제를 거절한다. 정기청구는 면제 업무를 제외하고 나머지만 합산한다. 전부 면제인 주기는 PG 호출 없이 다음 주기로 넘기며, 해지 예약 처리는 계속 수행한다. 면제 해제 후 미납 기간의 소급 청구를 방지하기 위해 해당 업무의 유료 라인아이템을 종료한다(보장가는 보존). 다시 유료로 쓸 때 사용자가 구독해야 한다.

## 관리자 화면과 API

- `/admin/subscriptions`: 상단 독립 메뉴. 검색(Space·소유자), 업무·상태 필터. Space × 업무별 행, 소유자 이메일은 계정 상세 링크.
- 기존 `/admin/billing`: 상품 과금 설정과 최근 청구. 구독 현황은 새 페이지로 이동.
- 공간 상세 링크는 기존 `/admin/billing/[spaceId]`를 유지한다.
- `GET /api/admin/subscriptions`: 설치·이용정책·구독 이력이 있는 업무 목록. 구독 기록 없는 Space도 설치 업무가 있으면 포함한다.
- `PATCH /api/admin/subscriptions/[spaceId]/[deckAppId]`: `{ trialEndsOn, note }` 또는 `{ exempt, note }`. 운영자+MFA, Zod 검증, 변경 전후 이력과 대상 업무를 transaction으로 기록한다.
- 기존 전체 면제 조작도 새 페이지에서 제공하되 업무별 면제와 명시적으로 구분한다.
- 체험 변경은 기존 유료 아이템이 없는 업무에만 허용한다. 과거 날짜·기존 종료일보다 이른 날짜·미시작 체험은 거절한다. 만료된 체험은 미래 날짜로 연장 가능하다.
- 사용자 구독 화면도 업무별 체험 종료일과 면제를 표시한다. 공간 전체 Trial 안내는 제거한다.

## 검증과 범위

업무 간 체험·면제 격리, 재추가·동시 요청, 체험 연장·날짜 경계·인가·감사로그 원자성, 면제 청구 제외, 면제 해제 소급 청구 방지, 기존 면제 보존을 테스트한다. Jest, typecheck, lint, build를 실행한다. 운영 환경 데이터 변경과 배포는 이번 로컬 구현에 포함하지 않는다.
