## 단계 (B → C → A+템플릿)

사용자는 「추천 순서대로」 진행을 지시했고, 템플릿 선택·관리 UI를 범위에 추가했다. 순서는 추천 B(지원자 동선) → 함께 제안한 C(정보 구조) → A(공고 제작)로 해석했으며, 템플릿은 공고 제작 단계(A)에 포함한다.

참고: 위저드 템플릿 선택 팝업은 항목을 고르면 우측에 블록 미리보기를 이미 보여 준다(`content-block-editor.tsx`의 `previewContents`). 부족한 것은 한눈에 비교할 썸네일, 자체/제공 템플릿 구분, 관리 화면의 미리보기다.

각 단계는 별도 PR(base=develop) → develop 환경 검증 → release PR(main)로 진행한다. 스키마 변경 없이 UI·조회 로직만 바꾸는 것을 원칙으로 하고, 필요해지면 해당 단계에서 별도로 보고한다.

### 1단계 — 지원자 중심 동선 (B)

1. 지원자 목록
   - 상단 단계 탭: `진행 중(서류 접수 n · 면접 n · 최종 제안 n) | 합격 n | 불합격 n | 전체`. 기존 `stage`(결과) URL 파라미터에 `process`(hiringStage) 파라미터를 더한다. 인원 수는 현재 필터(공고·기간·검색)를 반영한 groupBy 1회로 계산한다.
   - 검색: 이름·휴대폰 끝 4자리 입력 1개 + 「근무지·직무」 조건은 필터 영역으로 이동. Enter/디바운스 즉시 반영, 별도 [검색] 버튼 제거.
   - 행을 실제 링크로(새 탭·우클릭 가능). 열 이름 정리: 「결과·단계」를 하나의 「진행 상태」로 합치고 「표시」는 중복·직접 등록·블랙리스트 아이콘 열로 명확히.
2. 홈
   - 「처리할 지원자」 요약: 진행 단계별 인원(클릭 시 목록 필터), 최근 7일 신규 지원 수.
   - 모집 중 공고(마감 임박 순) — 공고별 신규/진행 중 지원자 수와 「링크 복사」.
   - 최근 지원자 5명(마스킹 이름) 바로가기. 지원자 0명일 때는 기존 안내 유지.
3. 공고 상세
   - 상단 탭: `지원자 모집(링크·HTML·미리보기) | 지원자 n | 공고 내용`. 「지원자」 탭은 1의 목록 컴포넌트를 `posting` 고정으로 재사용한다.

완료 기준: 위 화면의 단위 테스트(필터·카운트·URL), typecheck·lint·build, 로컬 dev에서 합성 지원자로 데스크톱/모바일 확인, develop 환경 확인.

### 2단계 — 정보 구조 (C)

- 사이드바를 섹션으로 그룹: 「모집」 홈·공고·지원자 / 「설정」 공고 템플릿·메시지 템플릿·매장·직무·블랙리스트. 「새 공고」 CTA를 사이드바 상단에.
- 공고 목록: 행 링크화, 검색 즉시 반영, 행 메뉴에 「링크 복사」「마감」 추가. 상태 탭 정리(작성 중/모집 중/마감/보관 + 전체).
- 「연장」은 발행 잠금 정책(지원자 이력 보존)과 충돌하는지 확인 후 결정한다. 마감일만 늘리는 것이 허용되면 메뉴에 추가, 아니면 「복사해서 새 모집」 유지.

### 3단계 — 공고 제작 + 템플릿 (A)

1. 새 공고 시작: 다이얼로그에 「이전 공고 복사해서 시작」(최근 공고 목록) / 「새로 만들기」 선택지. 복사는 기존 복사 API 재사용.
2. 지원서 설정 단계에 지원자 화면 미리보기(기존 `application-form-preview` 활용 범위 확인).
3. 템플릿 선택(위저드 「템플릿 불러오기」)
   - 탭 분리: 「내 템플릿 | 워크덱 제공」. 「샘플」 용어를 「워크덱 제공」으로 바꾼다.
   - 목록을 썸네일 카드 갤러리로. 썸네일은 템플릿 블록을 축소 렌더링(기존 `ContentBlockPreview` 재사용, 화면에 보일 때만 불러오고 캐시)한다.
   - 카드 선택 시 큰 미리보기(PC/모바일 전환) + 「하단에 추가 / 기존 교체」 적용.
4. 템플릿 관리(사이드바 「공고 템플릿」, 현 「상세 템플릿」)
   - 같은 탭 구조와 썸네일 갤러리. 카드에서 미리보기, 내 템플릿은 이름 변경·삭제, 워크덱 제공은 「이 템플릿으로 새 공고」 또는 「내 템플릿으로 복사」(복사 API가 없으면 범위 밖으로 보고).
   - 빈 상태: 「공고 꾸미기에서 템플릿으로 저장」 안내 + 워크덱 제공 탭으로 이동.
