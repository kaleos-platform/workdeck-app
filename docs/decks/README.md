# Deck별 문서 (`docs/decks/`)

워크덱의 각 Deck 문서를 **deck id 기준 폴더**로 관리한다. 폴더 스켈레톤은 git에 커밋되어 모든 워크트리 체크아웃에 항상 존재한다.

## ⚠️ 핵심 규칙

- **Deck 문서는 반드시 커밋한다.** untracked 상태로 두면 `git worktree add`로 만든 워크트리에는 딸려오지 않고, 워크트리를 제거하면 함께 소멸한다.
- 폴더명은 **코드의 정식 deck id**를 따른다 (`src/lib/deck-meta.ts`의 `DeckVariant`와 동기화).

## 하위 폴더 컨벤션

각 deck 폴더 안에서 아래 이름을 사용한다(필요한 것만).

| 폴더           | 용도                                   | 추적         |
| -------------- | -------------------------------------- | ------------ |
| `prd/`         | 제품 요구사항 문서                     | ✅ 커밋      |
| `roadmap/`     | 로드맵                                 | ✅ 커밋      |
| `guides/`      | 배포·운영·보안 가이드, 런북            | ✅ 커밋      |
| `source_refs/` | 샘플 데이터(xlsx 등)                   | ✅ 커밋      |
| `assets/`      | 문서에 넣을 **영구** 이미지·다이어그램 | ✅ 커밋      |
| `screenshot/`  | QA용 **전이성** 스크린샷               | ❌ gitignore |

## 이미지 정책

- **영구 보존·워크트리 간 공유가 필요한 이미지** → `assets/`에 둔다(추적됨).
- **QA 중 잠깐 쓰는 스크린샷** → `screenshot/`에 둔다. `.gitignore`의 `docs/decks/**/screenshot/` 규칙으로 추적하지 않으므로 로컬에만 남고 워크트리 간 공유되지 않는다.
