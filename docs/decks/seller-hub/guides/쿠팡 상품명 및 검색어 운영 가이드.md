# 쿠팡 상품명 및 검색어 운영 가이드

> Version 1.0  
> 적용 채널: 쿠팡  
> 목적: 상품의 검색 발견성, 클릭 가독성, 구매 전환 가능성을 높이면서 쿠팡 상품등록 정책을 안정적으로 준수하기 위한 내부 운영 기준

---

# 1. 운영 원칙

쿠팡 상품 등록 시 검색 노출을 결정하는 정보는 상품명 하나가 아니다.

쿠팡은 다음 정보를 함께 검색에 활용한다.

- 카테고리
- 상품명
- 검색어
- 구매 옵션
- 검색 옵션
- 브랜드 등 상품 주요정보

따라서 모든 키워드를 상품명에 넣는 방식보다 각각의 영역에 맞게 정보를 분배하는 것이 중요하다. 쿠팡 공식 가이드 역시 검색어와 구매/검색 옵션을 상품명·카테고리와 함께 검색엔진이 상품을 찾는 주요 정보로 설명한다.

## 핵심 원칙

> **상품명 = 고객이 상품을 이해하고 선택하기 위한 핵심 정보**  
> **검색어 = 상품명에 담지 못한 검색 의미 확장**  
> **검색 옵션 = 상품의 구조화된 속성 정보**

운영 우선순위는 다음과 같다.

1. 정확성
2. 고객 이해도
3. 검색 관련성
4. 검색량
5. 키워드 개수

즉,

> **검색량이 높은 키워드보다 상품과 정확하게 일치하는 키워드를 우선한다.**

---

# 2. 쿠팡 상품정보 구조

## 2.1 노출상품명

고객에게 실제로 보여지는 상품명이다.

쿠팡에서는 판매자가 입력한 상품명이 그대로 노출되는 것이 아니라 쿠팡 기준에 따라 노출상품명이 변경될 수 있다.

따라서 상품명은 검색 키워드 나열보다 **고객이 빠르게 상품을 이해할 수 있는 구조**를 우선한다.

---

## 2.2 등록상품명

판매자가 상품을 관리하기 위한 이름이다.

내부 관리가 목적이므로 필요한 경우 다음과 같은 내부 식별 정보를 활용할 수 있다.

```text
브랜드 / 상품군 / 모델 / 세트 / 내부 SKU
```

단, **고객에게 노출되는 상품명과 내부 관리용 상품명을 구분한다.**

---

# 3. 상품명 기본 구조

## 권장 기본 구조

```text
[브랜드] [라인/모델] [핵심 특징] [메인 상품 키워드] [추가 특징] [규격/수량]
```

또는 상품 유형에 따라 다음처럼 단순화한다.

```text
[브랜드] [핵심 특징] [상품 종류] [서브 특징] [규격/수량]
```

### 예시

```text
모노홈 40수 코마사 호텔 타월 200g 5장
```

```text
모노웨어 여성 텐셀 모달 미디 팬티 3매
```

```text
라이프랩 초경량 자동 골프 우산 대형 120cm
```

쿠팡 판매 실무 자료에서는 브랜드·핵심 키워드·서브 키워드·상품 특성을 조합하는 방식을 공통적으로 권장한다. 특히 쿠팡 내부 자동완성 및 연관검색어를 활용해 실제 고객이 사용하는 표현을 찾는 것이 중요하다는 점이 반복해서 강조된다.

---

# 4. 상품명 구성 요소

## 4.1 브랜드

원칙적으로 가장 앞에 배치한다.

```text
[브랜드] + ...
```

### 좋은 예

```text
모노홈 호텔 타월 40수 200g 5장
```

브랜드는 판매자명이나 쇼핑몰명이 아니라 **실제 상품 브랜드**를 사용한다.

쿠팡은 상품 주요정보에서도 브랜드를 별도로 관리하고 있으며, 정확한 브랜드 입력이 검색 노출에도 활용된다고 안내한다.

---

# 5. 메인 키워드 선정

메인 키워드는 고객이 해당 상품을 가장 일반적으로 부르는 표현이다.

예:

| 상품        | 메인 키워드 |
| ----------- | ----------- |
| 호텔 수건   | 타월 / 수건 |
| 여성 속옷   | 여성 팬티   |
| 자동 우산   | 우산        |
| 베개 커버   | 베개커버    |
| 아기 수건   | 아기 타월   |
| 운동용 양말 | 스포츠 양말 |

## 메인 키워드 선정 기준

다음 순서대로 판단한다.

### ① 고객이 실제 사용하는 표현인가?

제품 내부 용어나 전문용어보다 고객이 검색하는 표현을 사용한다.

### ② 쿠팡 자동완성에 등장하는가?

쿠팡 검색창에서 직접 확인한다.

### ③ 연관검색어에 나타나는가?

메인 키워드를 검색하고 관련 검색어를 확인한다.

### ④ 경쟁 상품에서 반복적으로 사용되는가?

검색 상위 상품에서 공통적으로 사용되는 표현을 참고한다.

단, 경쟁사의 브랜드명은 가져오지 않는다.

쿠팡 공식 가이드도 자동완성검색어와 연관검색어를 활용해 실제 고객이 사용하는 관련 검색어를 찾도록 권장한다.

---

# 6. 서브 키워드 선정

서브 키워드는 상품 종류보다 **고객이 상품을 선택하는 이유**를 표현한다.

예를 들어 타월이라면:

```text
메인 키워드
타월
```

서브 키워드 후보:

```text
호텔
40수
코마사
도톰한
대형
세면
흡수
```

여성 팬티라면:

```text
메인 키워드
여성 팬티
```

서브 키워드 후보:

```text
모달
텐셀
미디
데일리
부드러운
순면 안감
```

서브 키워드는 다음과 같이 분류한다.

| 유형      | 예시                 |
| --------- | -------------------- |
| 소재      | 모달, 울, 코마사, 면 |
| 형태      | 미디, H라인, 긴팔    |
| 기능/특징 | 생활방수, 경량       |
| 용도      | 골프, 여행, 데일리   |
| 대상      | 여성, 남성, 아동     |
| 스타일    | 호텔, 클래식         |
| 규격      | 200g, 120cm          |
| 구성      | 3매, 5장             |

상품의 형태·소재·별칭·상위분류·특장점·용도·스타일·브랜드 영문명 등은 쿠팡 공식 가이드에서도 검색어 후보 유형으로 제시된다.

---

# 7. 상품명 길이 규칙

## 내부 운영 기준

```text
목표: 40~70자
권장 최대: 80자
절대 운영 상한: 120자
```

단순히 120자를 채우는 것이 목표가 아니다.

2025년 10월 쿠팡 상품명 정책 업데이트 내용을 정리한 판매자 자료에서는 최대 120자, 모바일 가독성을 고려한 80자 이하를 권장 기준으로 소개하고 있다. 이 항목은 현재 공개된 쿠팡 마켓플레이스 페이지에서 동일 문구를 직접 확인할 수 없으므로, 내부적으로는 **80자 이하를 보수적인 관리 기준**으로 사용한다.

---

# 8. 상품명에서 금지하는 것

## 8.1 키워드 반복

### 나쁜 예

```text
여성 팬티 모달 팬티 여성 속옷 팬티 편한 팬티
```

### 좋은 예

```text
여성 텐셀 모달 미디 팬티 3매
```

같은 핵심 단어를 여러 번 반복한다고 검색 의미가 계속 증가하는 것은 아니므로 한 번의 정확한 사용을 기본으로 한다. 판매 실무 자료에서도 같은 핵심 키워드의 반복은 필요하지 않다고 설명한다.

---

## 8.2 프로모션 문구

상품명에는 다음과 같은 문구를 사용하지 않는다.

```text
무료배송
특가
할인
세일
최저가
대박특가
인기상품
신상품
1+1
BEST
강력추천
```

최근 상품명 정책을 정리한 판매자 자료에서는 프로모션·주관적 표현·배송 관련 문구 등을 제한 대상으로 안내하고 있다.

---

## 8.3 판매자 이름

다음과 같이 사용하지 않는다.

```text
철수마켓 추천
OO스토어 인기상품
판매자 직접배송
```

상품 브랜드와 판매자명은 구분한다.

---

## 8.4 과도한 특수문자

사용하지 않는다.

```text
[HOT]
★특가★
!!!추천!!!
♥BEST♥
<<<할인>>>
```

상품명은 일반적인 문장형 띄어쓰기를 사용한다.

---

## 8.5 경쟁 브랜드

자사 상품이 아닌 경쟁 브랜드를 검색 노출 목적으로 포함하지 않는다.

### 금지 예

```text
나이키 스타일 운동화
유니클로 같은 티셔츠
OO브랜드 대체품
```

쿠팡 공식 지식재산권 가이드도 상품명이나 상품 설명에는 해당 상품과 관련 있는 상표만 사용하도록 안내한다.

---

# 9. 검색어의 역할

검색어는 상품명을 다시 작성하는 영역이 아니다.

## 잘못된 방식

상품명:

```text
모노홈 40수 코마사 호텔 타월 200g 5장
```

검색어:

```text
모노홈
40수
코마사
호텔
타월
200g
5장
호텔 타월
호텔타월
40수 타월
코마사 타월
```

→ 대부분 상품명과 중복된다.

---

## 올바른 방식

상품명:

```text
모노홈 40수 코마사 호텔 타월 200g 5장
```

검색어 후보:

```text
세면 수건
욕실 수건
두꺼운 수건
답례품 수건
페이스 타월
데일리 수건
```

쿠팡은 상품명과 카테고리에 이미 포함된 단어는 검색조건으로 활용되므로 검색어에 다시 입력할 필요가 없다고 명시한다.

---

# 10. 검색어 입력 규칙

쿠팡 검색어는 쉼표로 구분하며 **최대 20개**까지 등록할 수 있다.

## Rule 1. 상품명에 있는 키워드는 제외한다

상품명:

```text
여성 텐셀 모달 미디 팬티
```

검색어에 다시 다음을 넣지 않는다.

```text
여성
텐셀
모달
미디
팬티
```

그 자리를 다른 검색 의도를 표현하는 단어에 사용한다.

---

# 11. 띄어쓰기 중복 금지

다음처럼 두 개를 동시에 넣지 않는다.

```text
호텔타월
호텔 타월
```

하나만 사용한다.

```text
호텔 타월
```

쿠팡 공식 검색어 가이드는 띄어쓰기 적용/미적용 형태를 중복 입력하지 말고 정상적으로 띄어 쓴 한 가지 형태만 사용할 것을 안내한다.

---

# 12. 키워드 조합 반복 금지

다음처럼 조합을 모두 만들지 않는다.

```text
여성 속옷
여성 모달 속옷
모달 여성 속옷
여성 편한 속옷
편한 여성 속옷
```

쿠팡에서는 동일 단어의 순서를 바꾸거나 반복적으로 조합할 필요가 없다고 안내한다.

가능하면 의미 단위로 관리한다.

```text
여성 속옷
데일리
부드러운 원단
```

---

# 13. 검색어 후보 분류 체계

검색어를 무작정 찾지 않고 아래 유형으로 분류한다.

## A. 동의어

```text
타월 → 수건
팬티 → 언더웨어 / 속옷
```

## B. 상위 카테고리

```text
삼각팬티 → 여성 속옷
골프우산 → 우산
```

## C. 소재

```text
코마사
모달
텐셀
울
기모
```

## D. 형태

```text
미디
하이웨이스트
긴팔
라운드
대형
```

## E. 용도

```text
골프
여행
데일리
욕실
세면
```

## F. 특징

```text
경량
생활방수
도톰한
```

## G. 별칭 및 영문명

실제로 고객이 사용하는 경우에 한해 사용한다.

```text
towel
underwear
```

---

# 14. 검색어 후보 수집 방법

검색어는 다음 순서로 찾는다.

## Step 1. 상품 Fact 정리

먼저 상품에 실제로 해당되는 정보만 적는다.

```text
제품 종류:
소재:
형태:
주요 특징:
사용 대상:
사용 상황:
크기:
수량:
인증:
고객이 자주 사용하는 표현:
```

---

## Step 2. 메인 키워드 선정

예:

```text
타월
```

---

## Step 3. 쿠팡 자동완성 조사

쿠팡 검색창에서 메인 키워드를 입력한다.

예:

```text
타월
```

자동완성되는 키워드를 수집한다.

쿠팡 공식 가이드 및 판매 실무 자료 모두 자동완성 검색어를 중요한 키워드 조사 수단으로 권장한다.

---

# 15. 연관검색어 조사

메인 키워드 검색 결과에서 연관검색어를 추가로 수집한다.

예:

```text
타월
호텔타월
세면타월
수건
답례품수건
```

단,

> **검색량이 많다는 이유만으로 넣지 않는다.**

실제 상품과 일치하는 키워드만 선택한다.

---

# 16. 경쟁 상품 조사

검색 상위 상품을 조사한다.

확인 항목:

- 상품명에서 반복되는 일반 키워드
- 고객 리뷰에서 반복되는 표현
- 고객이 상품을 표현하는 단어
- 소재
- 사용 상황
- 용도

경쟁 상품 조사는 **키워드 아이디어를 찾는 용도**로만 사용한다.

경쟁 브랜드명 자체를 검색어로 등록하지 않는다.

---

# 17. 키워드 후보 평가

모든 후보 키워드는 아래 기준으로 평가한다.

| 평가 항목                | 점수 |
| ------------------------ | ---: |
| 상품과 정확히 일치       |   +3 |
| 명확한 구매 의도         |   +3 |
| 쿠팡 자동완성 등장       |   +2 |
| 연관검색어 등장          |   +2 |
| 고객 리뷰에서 반복       |   +1 |
| 상품명과 중복            |   -2 |
| 카테고리와 단순 중복     |   -1 |
| 상품과 부분적으로만 관련 |   -2 |
| 경쟁 브랜드              | 제외 |
| 사실과 다른 표현         | 제외 |

예:

| 키워드        | 관련성 | 구매의도 | 자동완성 | 중복 | 결정                   |
| ------------- | -----: | -------: | -------: | ---: | ---------------------- |
| 세면 수건     |      3 |        3 |        2 |    0 | 사용                   |
| 호텔 타월     |      3 |        3 |        2 |   -2 | 상품명에 있으므로 제외 |
| 극세사 수건   |      0 |        2 |        2 |    0 | 제외                   |
| 답례품 수건   |      2 |        3 |        2 |    0 | 후보                   |
| OO브랜드 수건 |      - |        - |        - |    - | 제외                   |

---

# 18. 검색어 우선순위

20개를 무조건 채우지 않는다.

우선순위는 다음과 같다.

```text
1순위: 상품과 정확히 일치하는 다른 검색 표현
2순위: 구매 의도가 높은 용도
3순위: 소재/형태/특징
4순위: 상위 개념
5순위: 별칭/영문명
```

검색량이 많더라도 실제 상품과 관련 없는 검색어는 사용하지 않는다.

쿠팡은 상품과 무관한 검색어 및 경쟁 브랜드 사용을 금지하고 있으며, 부적절한 검색어는 검색에 활용되지 않거나 상품 노출에 영향을 줄 수 있다고 안내한다.

---

# 19. 검색어 금지 규칙

## 사용하지 않는다

### 다른 브랜드

```text
나이키
아디다스
유니클로
```

자사 상품이 해당 브랜드 상품이 아니라면 사용 금지.

---

### 상품과 다른 속성

상품:

```text
장우산
```

검색어:

```text
3단 우산
```

→ 금지.

상품과 관계없는 키워드는 검색 노출뿐 아니라 전환율에도 악영향을 줄 수 있으므로 사용하지 않는다. 판매 실무 자료에서도 이 원칙을 강하게 권장한다.

---

### 배송 관련

```text
무료배송
빠른배송
당일배송
```

검색어로 사용하지 않는다.

---

### 검증하기 어려운 효능

```text
피부병 예방
질병 예방
간에 좋은
치료
다이어트 효과
```

객관적으로 입증되지 않은 효능이나 기능성 표현은 사용하지 않는다.

쿠팡 공식 검색어 가이드도 배송 관련 문구 및 검증하기 어려운 기능성 표현을 검색어로 입력하지 않도록 안내한다.

---

# 20. 검색 옵션 관리

검색어와 별도로 **검색 옵션을 가능한 정확하고 충분하게 입력한다.**

예를 들어 의류라면:

```text
색상
사이즈
소재
성별
사용 계절
스타일
```

상품에 해당되는 옵션이 있다면 검색어에 키워드를 억지로 추가하는 것보다 검색 옵션에 정확하게 넣는다.

쿠팡은 검색 옵션이 검색결과 필터 및 상품 검색에 활용되며, 카테고리에서 제공되는 검색 필터 속성을 가능한 한 충실하게 입력할 것을 권장한다.

---

# 21. 상품명 vs 검색어 vs 검색옵션

동일 정보를 세 영역에 불필요하게 반복하지 않는다.

예를 들어 다음 상품이 있다고 가정한다.

```text
여성
모달
팬티
블랙
M
3매
```

## 상품명

```text
모노웨어 여성 텐셀 모달 미디 팬티 3매
```

## 구매 옵션

```text
색상: 블랙
사이즈: M
```

## 검색 옵션

```text
성별: 여성
소재: 모달
색상계열: 블랙
```

## 검색어

```text
여성 속옷
데일리 언더웨어
부드러운 원단
미디 속옷
```

이처럼 정보를 분산한다.


## STEP 08. 중복 제거

다음에 이미 포함된 키워드는 우선 제외한다.

# 25. 상품명 변경 관리

상품명이 성과가 좋지 않다고 자주 변경하지 않는다.

상품명 변경은 다음 사유가 있을 때 진행한다.

### 변경 가능

- 잘못된 메인 키워드
- 상품을 이해하기 어려운 상품명
- 정책 위반 가능성
- 새로운 검색 데이터에서 명확한 개선 근거 발견
- 실제 제품 사양 변경
- 브랜드/모델 변경

### 변경하지 않음

```text
노출이 조금 줄었다
광고 성과가 며칠 좋지 않다
경쟁사가 상품명을 변경했다
키워드를 하나 더 발견했다
```

검색 발견성을 개선하려면 먼저 다음 순서로 확인한다.

```text
검색어
→ 검색 옵션
→ 카테고리
→ 상품 정보
→ 상품명
```

---

# 26. 변경 기록

상품명이나 검색어를 변경할 때 반드시 기록한다.

```text
변경일:
상품:
기존 상품명:
변경 상품명:
기존 검색어:
변경 검색어:
변경 이유:
관찰 지표:
담당자:
```

가능하면 여러 요소를 동시에 바꾸지 않는다.

그래야 어떤 변경이 성과에 영향을 주었는지 판단하기 쉽다.

# 28. 상품명 체크리스트

상품 등록 전 확인한다.

- [ ] 브랜드명이 정확한가?
- [ ] 고객이 상품 종류를 바로 이해할 수 있는가?
- [ ] 메인 키워드가 1개 이상 포함되어 있는가?
- [ ] 중요한 특성이 1~3개 포함되어 있는가?
- [ ] 같은 키워드를 반복하지 않았는가?
- [ ] 상품과 무관한 인기 키워드가 없는가?
- [ ] 경쟁 브랜드가 포함되어 있지 않은가?
- [ ] 할인/특가/무료배송 등의 표현이 없는가?
- [ ] 과도한 특수문자가 없는가?
- [ ] 객관적으로 증명하기 어려운 효능 표현이 없는가?
- [ ] 수량 및 규격이 실제 상품과 일치하는가?
- [ ] 80자 내외로 읽기 쉬운가?
- [ ] 모바일 화면에서 앞부분만 보더라도 상품 종류를 이해할 수 있는가?

---

# 29. 검색어 체크리스트

- [ ] 최대 20개 이내인가?
- [ ] 상품명과 중복되는 단어를 제거했는가?
- [ ] 카테고리명만 반복해서 넣지 않았는가?
- [ ] 띄어쓰기 버전을 중복해서 넣지 않았는가?
- [ ] 단어 순서만 바꾼 키워드를 중복하지 않았는가?
- [ ] 상품과 직접적으로 관련 있는가?
- [ ] 경쟁 브랜드가 없는가?
- [ ] 실제 존재하지 않는 기능이 없는가?
- [ ] 배송/할인/프로모션 키워드가 없는가?
- [ ] 자동완성 검색어를 확인했는가?
- [ ] 연관검색어를 확인했는가?
- [ ] 구매 의도가 높은 키워드를 우선했는가?
- [ ] 검색옵션으로 입력 가능한 정보는 검색옵션에도 정확하게 등록했는가?

---

# 30. 최종 의사결정 원칙

상품명이나 검색어를 결정하기 어려울 때는 다음 순서로 판단한다.

```text
정책 적합성
↓
상품과의 정확한 관련성
↓
고객의 이해도
↓
구매 의도
↓
쿠팡 내부 검색 데이터
↓
검색량
```

따라서,

> **“검색량이 높으니까 넣는다”가 아니라  
> “이 상품을 찾는 고객이 실제로 사용할 표현인가?”를 기준으로 결정한다.**

---

# 31. 한 줄 운영 규칙

> **상품명에는 상품을 설명하는 가장 중요한 단어만 넣고, 상품명에 넣지 못한 관련 검색 의도는 검색어와 검색 옵션으로 확장한다.**

---

# 32. 요약

## 상품명

```text
브랜드
+
핵심 특징
+
메인 상품명
+
차별화 특징
+
규격/수량
```

## 검색어

```text
상품명에 없는
+
상품과 직접 관련된
+
고객이 실제 검색하는
+
동의어/용도/특징/상위개념
```

## 검색옵션

```text
색상
사이즈
소재
대상
형태
용도
등 구조화 가능한 상품 속성
```

가장 중요한 운영 원칙은 다음 세 가지다.

# 참고 자료 및 기준

본 가이드는 다음 자료를 교차 검토하여 작성했다.

1. **쿠팡 마켓플레이스 — 검색어 입력 A to Z 꼼꼼한 가이드**  
   검색어 최대 20개, 상품명·카테고리와의 중복 제거, 자동완성/연관검색어 활용, 관련 없는 키워드 및 타 브랜드 사용 금지 등의 기준.

2. **쿠팡 마켓플레이스 — 구매/검색 옵션 제대로 설정하기**  
   상품명·검색어·카테고리와 함께 구매/검색 옵션이 검색에 활용되며 가능한 검색 필터를 정확하게 입력하도록 안내.

3. **쿠팡 마켓플레이스 — 상품등록 가이드**  
   노출상품명과 등록상품명의 구분, 브랜드 정보, 최대 20개의 검색어 및 검색필터 관리 기준.

4. **쿠팡 로켓그로스 — 돈버는하마의 로켓그로스 팁 EP.1 상품등록**  
   노출 상품명의 가독성과 쿠팡 내부 키워드 활용을 주요 상품등록 포인트로 소개.

5. **아이보스 — 쿠팡에서 매출 상승하는 상품명 최적화 방법**  
   메인 키워드와 고객 니즈를 표현하는 서브 키워드의 구분 및 조합 전략 참고.

6. **장사왕 — 쿠팡 상품명 정책 업데이트 정리**  
   2025년 10월 상품명 정책 업데이트로 소개된 글자 수, 반복 표현, 특수문자, 프로모션 문구 등의 제한 사항 참고. 공개된 쿠팡 공식 페이지에서 동일한 전체 공지 원문을 직접 확인하지 못했으므로 내부적으로 보수적인 운영 기준으로 활용한다.

7. **셀러나우 — 상위 셀러 상품명 작성 및 등록 전략**  
   쿠팡 자동완성·연관검색어 기반 키워드 조사 및 상품명/검색어 분리 운영 방법 참고.

**문서 관리 원칙**

쿠팡 정책이나 상품 등록 UI가 변경되는 경우 이 문서를 업데이트한다.

```text
현재 버전: 1.0
채널: Coupang
다음 확장 후보:
- 네이버 스마트스토어
- 11번가
- G마켓
- 자사몰 SEO
```

장기적으로는 채널별 규칙을 별도로 관리하되, `상품 마스터`의 상품 Fact와 기본 키워드는 공통 데이터로 관리하고 각 판매채널에 맞게 상품명과 검색어만 변환하는 구조를 권장한다.
